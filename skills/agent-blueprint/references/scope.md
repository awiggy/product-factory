# 功能范围

## 负责什么

需求事实 → 领域五要素 → 必要组件 → 架构方案 → 实现交接。

提供 17 类机制的选型索引，帮助明确组件的需求依据、权限边界、预算和完成证据。它是架构推导 Skill，不是直接运行的 Agent 应用。

## 设计原则

- 小型方案可合并层级，不为七层图创造额外复杂度。
- 支持确定性工作流、动态 Agent 与混合方案。
- 已有批准与实现请求不重复阻塞；新增业务、成本或权限决定仍需明确。
- 上下文和记忆按需加载，记录必要事实与证据。
- 方案、可运行骨架、测试通过与生产验收是不同状态。

## 不包含什么

不包含 17 类机制的配套代码、自动建项目脚本或模型 SDK，不默认调用外部服务。实现阶段需根据目标项目选择工具、审查代码并进行实际测试。

本 Skill 可以独立读取；不依赖其他 Skill 或仓库外文件。
