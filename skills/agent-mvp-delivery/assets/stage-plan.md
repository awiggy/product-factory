## 阶段划分

每个阶段都要能独立运行、独立验收；不要按“先写完所有后端再做前端”拆。

## 第 N 阶段详细计划

### 目标
本阶段完成后用户能做什么。

### 环境与配置
运行时版本、启动命令、端口；需要的环境变量名（无值）；模型与调用参数来源。

### 数据、资产与状态
实体与持久化方式；任务状态及迁移规则；文件存放与归属。

### API / 工具
| 接口或工具 | 输入 | 输出 | 错误 | 副作用与幂等 |
| --- | --- | --- | --- | --- |

### Prompt
文件位置与版本方式；格式约束（正例 + 禁止的反例）；解析器兼容的等价格式。

### 测试
- mock 自动化：覆盖的业务规则、状态迁移、错误路径、解析器。
- 真实冒烟：每种模型调用契约、每条关键链路至少一条真实路径。

### 验收清单
对应 AC 的逐条验证方式与预期结果。
