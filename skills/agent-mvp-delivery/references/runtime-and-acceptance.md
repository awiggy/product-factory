# Agent 运行与验收

## 模型与工具

- 业务服务通过适配层调用模型；配置模型标识、超时与最大输出，不在页面内放密钥。
- 校验输出字段及业务约束。结构合法不代表事实正确；使用固定测试案例检查业务含义。
- 工具按允许列表提供，分别限制执行权限、总步数、总时间、费用或 token 预算。
- 外部写入需要对应用户授权；把模型建议、用户批准、实际执行分别记录。批准前不要先执行。
- 失败重试要有上限。涉及发送、付费、下单等副作用，先确认执行状态与幂等策略，不能盲目重放。
- 记录请求/任务 ID、版本、耗时和错误类别；日志不保存密钥、完整敏感输入或隐藏推理过程。

## 状态与数据

长任务用服务端 task ID 和明确状态迁移，不把进程内变量或浏览器状态当持久事实。可按需要采用 queued、running、awaiting_confirmation、succeeded、partially_succeeded、failed、cancelled；不强制无关状态。

取消请求与取消完成不同；超时或断开连接不代表后端失败。查询原任务后决定恢复、继续等待或重新提交。持久化结果与历史读取分离，打开历史不再次调用模型。

数据库记录输入版本、模型/提示词版本和产物关联；文件记录所有者、类型、大小与保存位置。校验上传类型、大小与路径；下载仍需鉴权。开发样例不覆盖真实数据。

## 四类证据

| 验证层 | 验证什么 | 不能证明什么 |
| --- | --- | --- |
| 单元/契约测试 | 校验、业务规则、错误映射 | 真实供应商可用 |
| mock 闭环 | UI/API 状态与可复现分支 | 模型质量、真实计费 |
| 已授权真实服务冒烟 | 连通性、实际输入输出与错误处理 | 所有场景或长期稳定性 |
| 用户验收 | 目标流程和体验符合需要 | 未覆盖的安全与可靠性 |

按本阶段风险检查：权限隔离、空输入、非法模型输出、供应商超时、重复提交、任务恢复、历史一致性。没有模型配置时保留可运行的 mock 测试并列出真实验收缺口，不索取聊天明文密钥，不自费或擅自开通服务。

完成报告要写实际命令/操作、环境、结果和证据位置；不得只凭“代码已写完”或“生成成功”宣称阶段验收通过。
