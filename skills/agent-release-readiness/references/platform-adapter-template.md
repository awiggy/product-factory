# 平台适配器模板

接入新平台（其他云函数、容器平台、公司内部平台）时，先按此模板整理一页要点，写进发布记录或本目录新文件，再执行。每条都写来源（官方文档链接或 CLI 帮助）和核对日期；查不到的写“未核实”，不当作事实。

## 1. 平台与账号
- 平台、区域、账号类型限制（个人/企业）：
- 需要用户本人完成的步骤：
- 凭据方式：用户本机登录 / 平台密钥管理 / CI 密钥；AI 不经手明文

## 2. 最小权限
- 本次用到的服务与对应策略（优先细粒度）：
- 临时权限与收回时间：

## 3. 运行形态
- 函数 / 容器 / 虚拟机；实例扩缩容方式；冷启动
- 本地磁盘是否持久、哪些目录可写
- 运行时版本；启动命令与端口要求
- 打包排除方式（ignore 文件）

## 4. 数据与文件
- 托管数据库选项、开通条件、备份与恢复能力
- 对象存储：私有桶、签名下载、S3 兼容参数
- 不可用作唯一事实源的位置

## 5. 网络与入口
- 公网入口、HTTPS、自定义域名与备案要求
- 前后端同源代理方式

## 6. 配置与发布
- 环境变量设置方式；是否需要在首次发布前设置
- 部署命令；版本标识方式；回滚到上一版本的方式
- 已知坑与报错

## 7. 费用
- 各资源计费方式（按量/包月）与量级；可能产生意外费用的开关

## 8. 验证方法
- 如何确认线上版本；日志与告警入口；如何在不影响真实用户的前提下做业务验证
